# Web fundamentals

Completed HTML, CSS, and JavaScript exercises collected in one place. Each exercise is independent and uses plain browser files, with no dependency installation or build step.

## Exercise index

| Exercise | Focus | Open locally |
| --- | --- | --- |
| [Calculator](calculator/) | Browser events and arithmetic | [calculator/index.html](calculator/index.html) |
| [Etch-a-Sketch](etch-a-sketch/) | DOM events and a dynamic drawing grid | [etch-a-sketch/index.html](etch-a-sketch/index.html) |
| [DigiDen signup](digiden-signup-page/) | Signup form markup and styling | [digiden-signup-page/index.html](digiden-signup-page/index.html) |
| [ChronoVoyage form](chronovoyage-form-page/) | Semantic forms and native input validation | [chronovoyage-form-page/index.html](chronovoyage-form-page/index.html) |

## Run locally

Open an exercise's `index.html` directly in a browser, or serve this repository with a local static HTTP server and navigate to its directory. Each directory retains its original README and source files.
